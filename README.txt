GOOGLE DRIVE WIDGET

Use Desktop access to mount Google Drive in Explorer. Green means connected,
gray means disconnected, and amber means the widget is working on a change.

Save and close Drive files before switching off. Keep them closed until Drive
disconnects. The widget checks the rclone upload queue and waits for two fresh
idle reports. Some open file handles can escape detection. If activity can't
be verified, Drive stays mounted. Use Cancel to go back to work.

Drag the header to move the card. The small bar in the top-right corner hides
it. Click the tray icon or open the shortcut to show it again. The three-dot
menu has Keep on top, Status details, Help, and Quit widget.

Opening the widget displays the current status. Quitting the widget leaves
the mount in its current state. The widget follows the Windows app theme.

For setup, troubleshooting, and restore instructions, see README.md in
the source repository.
